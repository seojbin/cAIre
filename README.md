\#피쳐 추출기 -
각 축의 기본 통계, 궤적의 전체 길이, 궤적의 총 변위, 변위 대비 길이 비율, 시작-끝 지점의 축별 차이, 바운딩 박스 크기, PCA 주성분 분석으로
데이터 특성을 정리하는 코드. 시계열 데이터를 결정나무에서도 학습 가능하게 만듬.

이후 절대위치 피쳐 제거 후 위의 증강코드 추가 -> 정확도 개선

데이터 특징 주목 --- 대부분 y축만 이동, 왕복이동, 어깨를 축으로한 곡선 운동
최종 피쳐 정리
M1용(원) - Ratio류: Radius 중심부터 점까지 일정?, PCA 분산비 구하기 -> 면적이 크다
Convex hull -> XY 평면투영 면적으로 닫힌곡선인지 판단(결과상 수평운동이 평면면적 제일 큼, 원은 대각선보다 작음)
Max Deviation -> 왕복에서 제일 먼 점(apex)부터 점들의 수직거리값들 - 원일수록 큼

M2용(수평) - maxrange(제거) robust range로 대체 -> 퍼센트를 사용해 스케일링에 불감하도록 조정(x,y,z)
pca z, apex z - z로 얼마나 올라가고 z성분 많은지 분석
xy diagonal sum(추가!) - 기존 움직임 데이터가 y축에만 많아 90도회전시 인식하도록 추가

M3용(수직) - M2와 동일, 테스트시 부호만 반대.

M4용(대각좌우) - 노이즈 취약 >>위치기반으로. apex x,y사용, 무게중심 기반 출발점 centroid 위치 구하기
Delta Azimuth(추가!) - 기존 데이터가 90도 회전해도 인식하게 방위각 시계방향처럼 구하기



\#Decision tree 분석

단순 결정나무로는 circle, diagonal\_left, diagonal\_right처럼 복잡한 궤적들의 구분이 힘들었다.

단순 궤적인가 복잡한 궤적인가를 먼저 구분하고, 이후에 위의 복잡한 궤적들을 계층적으로 분류하는 dt\_train\_add를 새로 만들었다.

이후 대각선 좌우 구분이 어려워 두 부분을 구분하는 계층을 다시 추가, 총 4 계층의 결정나무로 만들었다.

대각선 좌우 구분의 경우 피쳐 추출기의 피쳐보다는 시간 순서가 보존된 원본 궤적으로 추론하는것이 성능이 좋아, 대각선 좌우 구분만 knn-DTW로 대체한 하이브리드 트리를 구성하였다.

이후 단순 궤적과 복잡한 궤적 분류가 노이즈에 취약하다는 것을 판단, 이를 knn으로 대체 후 knn, dtw 시각화코드 추가
