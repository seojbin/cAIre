\#데이터 증강과 전처리

s로 시작하는 데이터는 정지 상태를 나타내므로 움직임을 측정하는 r 데이터만 사용하도록 전처리, 폴더 단위로 라벨링

노이즈추가 : 각 좌표에 작은 정규분포 노이즈 추가

스케일링 : 전체좌표를 0.9-1.1배 비율로 스케일링

translation : 전체궤적 좌표를 방향성 유지한 상태에서 미세 이동

스케일링과 translation의 경우 대각선 예측은 좋아지지만, 원형 예측이 훼손되는 문제 발생.



\#피쳐 추출기 -
각 축의 기본 통계, 궤적의 전체 길이, 궤적의 총 변위, 변위 대비 길이 비율, 시작-끝 지점의 축별 차이, 바운딩 박스 크기, PCA 주성분 분석으로
데이터 특성을 정리하는 코드. 시계열 데이터를 결정나무에서도 학습 가능하게 만듬.

이후 몇 절대위치 피쳐 제거 후 위의 증강코드 추가 -> 정확도 개선



\#Decision tree 분석

단순 결정나무로는 circle, diagonal\_left, diagonal\_right처럼 복잡한 궤적들의 구분이 힘들었다.

단순 궤적인가 복잡한 궤적인가를 먼저 구분하고, 이후에 위의 복잡한 궤적들을 계층적으로 분류하는 dt\_train\_add를 새로 만들었다.

이후 대각선 좌우 구분이 어려워 두 부분을 구분하는 계층을 다시 추가, 총 4 계층의 결정나무로 만들었다.

대각선 좌우 구분의 경우 피쳐 추출기의 피쳐보다는 시간 순서가 보존된 원본 궤적으로 추론하는것이 성능이 좋아, 대각선 좌우 구분만 knn-DTW로 대체한 하이브리드 트리를 구성하였다.

이후 단순 궤적과 복잡한 궤적 분류가 노이즈에 취약하다는 것을 판단, 이를 knn으로 대체 후 knn, dtw 시각화코드 추가
